Our real run, for comparison

§6.1 printed balanced CONF = 0.292 (mean F1 over all classes), recall-first HEAD_CONF = 0.253 and precision-first ≈ 0.61 for head. Same shape as this table: asking for more recall pushes the threshold down.

The cost decides, not the habit

A missed bare head can mean an injury. A false alarm costs a walk to the site. So the alarm class runs recall-first.

The formula needs calibration

τ = cFP / (cFP + cFN) assumes "0.7 means right 70 % of the time". Check the §6.2 reliability diagram first. If it's far from the diagonal, choose from the measured curves instead.

The near-zero trap

The threshold is for deployment only. mAP is always measured at conf=0.001. Measure it at 0.29 and the truncated PR curve loses area (§6.1).
