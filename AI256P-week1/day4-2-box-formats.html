DAY 4 · EXERCISE 2 · BOX FORMATS

One box, three ways to write it.

A detector's ground truth is a set of boxes per image. The same rectangle can be written in different formats, and mixing them up is silent: training runs, the loss falls, and mAP sits near zero. Match each format to how it encodes a box.

Work with the person next to you. Agree on an answer together before you check it.

01The box

One image, 640 × 480 pixels, with a single helmet (class index 0).

The origin is the top-left corner: x grows to the right, y grows down.

Each encoding on the right shows its pattern and this exact box written in it. Use the numbers to check yourself.

Click an item on the left, then its match on the right. You can also drag from one dot to the other. Click again to change a match.

VOC → YOLO in four lines

x_c = (xmin + xmax) / 2 / W
y_c = (ymin + ymax) / 2 / H
w = (xmax − xmin) / W
h = (ymax − ymin) / H

Three things that bite

Clip boxes that run outside the image. Drop degenerate boxes (zero width or height). Keep images with no objects: they teach the model what nothing looks like.

Draw it back

Every box in the top-left corner → you forgot to normalise. Boxes mirrored → you swapped an axis. Wrong names → the class index map is wrong.
